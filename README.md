# NEBULA — Космическое выживание

**NEBULA** — браузерная игра в жанре Bullet Heaven, в которой игрок управляет космическим кораблём, сражается с противниками и улучшает вооружение.

**Ссылка на игру:** https://xolopenya.github.io/NEBULA/ 

### Как управлять

- **WASD или стрелки** — движение корабля.
- **Пробел** — рывок.
- **Esc** — пауза и продолжение игры.
- **Мышь** — выбор улучшений и перезапуск.

### Что нужно делать

Выживать, уклоняться от врагов и уничтожать их с помощью автоматически стреляющего оружия. Собирать выпадающий опыт, повышать уровень и выбирать улучшения корабля. Конечная цель — победить босса Стража.

При потере всего здоровья игра заканчивается. Нажатие кнопки «ПОВТОРИТЬ» начинает новый забег.

### Что пока не реализовано

Игра находится на стадии прототипа. Используются простые геометрические фигуры вместо полноценной графики. Пока отсутствуют звуковое сопровождение, сохранения и управление с мобильных устройств.

### Технологии

TypeScript, Phaser 4, Vite.

Для локального запуска:

```bash
npm ci
npm run dev
```
